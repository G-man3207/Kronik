# Definition of done: `unsafe` only in allowlisted modules with a
# justification). `scripts/ci.sh hygiene` fails on unsafe code in any other
# file under crates/ or sdk/rust/, and on an entry here that no longer has

# at its `allow`. One file per line: the path, then the reason.
