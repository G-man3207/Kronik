# M11 wildcard certificate for preview forks (DNS-01)

Status: binding for M11. Builds on ADR 0009 (gateway TLS and ACME) and the
M11 preview design (`m11-preview.md`); brief section "v0.2", M11. Decision:
ADR 0026.

Preview forks answer at `<id>.<preview_domain>`. With `[tls] mode = "acme"`
and a DNS-01 hook, the gateway gets one certificate, `*.<preview_domain>`,
for all of them, and serves it next to the main certificate. Without a
hook there is no wildcard certificate, so ACME with `preview_domain` and no
hook is refused at start; without `preview_domain`, preview forks use the
path prefix `/__preview/<id>` on the main name.
No new concept (I13): this is TLS configuration.

## 1. Configuration

| Key | Default | Meaning |
| --- | --- | --- |
| `[gateway] preview_domain` | none | The domain whose subdomains serve preview forks (shared with the preview slice) |
| `[tls] dns01_hook` | none | The executable that publishes the TXT records |
| `[tls] dns01_propagation` | `"60s"` | The wait after `present` before the CA checks |

`dns01_hook` without `mode = "acme"`, without `preview_domain`, or with a
`preview_domain` that is not a DNS name, is a config error at start (the
message names the missing key). `kronik doctor` adds a `dns01_hook` check:
the hook must be an executable file.

## 2. The hook contract

```
<hook> present _acme-challenge.<preview_domain>. <value>
<hook> cleanup _acme-challenge.<preview_domain>. <value>
```

- The fqdn ends with a dot; `value` is the TXT record's text (43 base64url
  characters), the same for `present` and `cleanup`.
- Exit 0 is success. A non-zero exit, a hook that can't be started, or one
  that runs longer than two minutes is a failure. The hook runs in its own
  process group; on timeout the whole group is killed, so a hung `curl` it
  started can't publish a record after `cleanup`.
- stdout and stderr are logged at `info` with the action and the exit status.
  The value is not a secret: it is published in DNS.
- A failed `present` fails the order; the task retries after a minute,
  doubling to an hour. `cleanup` runs for every `present` that was tried,
  after the order is valid or has failed; a failed `cleanup` is a warning.
- stdin is `/dev/null`; the environment is the daemon's minus
  `KRONIK_MASTER_KEY` and `KRONIK_TOKEN`. Credentials for the DNS API live
  wherever the hook reads them, never in `kronik.toml`.

The arguments are those of lego's `exec` provider (default mode), so an
existing lego script needs little or no change.

## 3. In the gateway

`kronik-gateway::tls`:

- `trait Dns01 { present, cleanup }` and `ExecHook { program, timeout }`, the
  only provider.
- `Acme::wildcard: Option<Wildcard { domain, dns01, propagation }>`. With
  it, `start` spawns a second renewal task beside the main one. Both share
  the account (created once, under a lock) and the cache directory of the
  CA; the wildcard's chain and key are `wildcard.<domain>.pem`, so a new
  `preview_domain` gets a new order rather than the old certificate.
- The order names `*.<domain>` and answers its authorization with DNS-01.
  Renewal is as for the main certificate: 30 days before expiry, checked at
  least every 12 hours.
- The resolver chooses by SNI: a TLS-ALPN-01 challenge when the client offers
  `acme-tls/1`; the wildcard for a name exactly one label below
  `preview_domain` (case-insensitive), as the certificate itself covers; the
  main certificate otherwise, including for `preview_domain` itself.

## 4. Tests

- `tls::tests`: the coverage rule; the hook's arguments; a failing, a slow
  and a missing hook are errors.
- `config::tests`: the three config errors; a hook adds the wildcard to the
  ACME settings.
- `doctor::tests`: the hook must be an executable file.
- `scripts/e2e-acme-pebble.sh`: against Pebble and pebble-challtestsrv, the
  gateway gets the main certificate by TLS-ALPN-01 and `*.preview.kronik.test`
  by DNS-01 through a hook that calls challtestsrv's management API
  (`/set-txt`, `/clear-txt`); HTTPS to `abc.preview.kronik.test` verifies
  against Pebble's root; after a restart both come from the cache.

## 5. Not included

- No built-in DNS provider (Cloudflare, Route 53, RFC 2136, acme-dns): the
  owner supplies the hook (ADR 0026).
- No check that `present` has propagated: the fixed wait is all.
- No routing: preview requests by host are the preview slice's
  (`m11-preview.md`).
